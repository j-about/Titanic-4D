as a record of what was consulted and how.

Each item is tagged with its provenance: read on a page, seen only in a search extract, known
through another work, or recalled from memory. Items recalled from memory were not used as
established facts. The dataset, not these notes, is the reference for the application; where
they differ, the dataset reflects later checks.
