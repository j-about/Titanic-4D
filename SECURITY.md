# Security policy

## Reporting a vulnerability

Please report any security problem in Titanic 4D or in <https://www.titanic-4d.org> by e-mail to
<contact@titanic-4d.org>. Do not open a public issue for it.

Include, as far as you can:

- the address or the file concerned;
- what you observed and how to reproduce it;
- the browser, the operating system and the date.

You will receive an acknowledgement, and the problem will be assessed and corrected as quickly
as its severity requires. Please allow a reasonable time for a correction before making the
details public.

## Scope

- The static site served at <https://www.titanic-4d.org> and its three redirecting hosts
  (`titanic-4d.org`, `www.titanic-4d.com`, `titanic-4d.com`).
- The code and the build of this repository.

The site has no accounts, no forms and no cookies, and loads nothing from third parties. The
payment pages linked from the About page are hosted and operated by Stripe; problems found there
should be reported to Stripe.

## Supported versions

Only the version currently deployed from the `master` branch is supported.
